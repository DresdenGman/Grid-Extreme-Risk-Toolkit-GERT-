# GERT Historical Lab — one-click notebook

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DresdenGman/Grid-Extreme-Risk-Toolkit-GERT-/blob/main/gert-historical-lab-colab.ipynb)

1. Open `gert-historical-lab-colab.ipynb` in Google Colab (File > Upload notebook), then "Runtime > Run all".
2. Nothing to install: it uses only Colab's preinstalled pandas/numpy/matplotlib and reads the 216 hourly ERCOT rows straight from the public Hugging Face dataset.
3. Do the hand calculation in section 3 first, type your answers into the checker cell, and run it to verify.
4. Every computed number is self-checked against the published reference values (21h / 66,683 MWh at 0%, 7h / 4,458 MWh at 5%).
